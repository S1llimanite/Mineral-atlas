# 科学数据政策

## 0. 总原则

科学准确性优先于一切。
所有具有科学含义的数据必须能够追溯到一个**明确来源**或解释生成方式。
数据缺失时显式标 missing，禁止用占位值冒充真实值。

## 1. 数据状态分级

| 状态 | 含义 | 必须满足 |
|---|---|---|
| `verified` | 已审核 | 有可靠来源，已通过专业核查 |
| `reviewed` | 已复核 | 已专业检查，部分字段仍待补充验证 |
| `provisional` | 暂定 | 来源明确，存在范围/条件不确定性 |
| `schematic` | 示意 | 程序生成或示意内容，非精确自然状态 |
| `draft` | 草稿 | 待审核 |
| `missing` | 缺失 | 尚未收集到可靠数据 |

## 2. 禁止做法

- 编造折射率、双折射率、光性正负号、2V 等数值
- 把理想晶形等同于岩石薄片中实际形态
- 把程序化几何描述为经过实验验证的真实晶形
- 宣称"已包含全部矿物种"——除非目标名录已明确并核对

## 3. 三种形态必须区分

| 形态 | 说明 | 当前实现 |
|---|---|---|
| 理想晶形 | 晶面与晶轴的几何示意 | CrystalViewer 程序化生成，全部 schematic |
| 岩石实际产状 | 自形/他形/粒状等受生长环境影响 | 详情页"产状与共生"区 |
| 薄片观察 | 切片方向与厚度影响单偏光/正交偏光特征 | 详情页 PPL/XPL 表格 |

## 4. 资料来源

按优先级使用：
1. 用户拥有合法使用权的《透明矿物薄片鉴定手册》
2. 具开放许可的数据集（RRUFF CC BY 4.0、Mindat）
3. 经核验的公开科学资料（教科书、标准文献）
4. 获授权的数据库接口
5. 自制并经审核的 3D 模型

禁止：
- 未经许可批量抓取受限数据库
- 大段复制受版权保护内容
- 直接使用无许可的显微照片或晶体插图

## 5. 来源记录要求

每个矿物的重要参数应记录：
- 来源名称、作者/机构、出版年份、页码/URL
- 访问时间（在线资源）
- 许可信息
- 审核状态

`REFERENCE` 表统一管理，`PROPERTY_SOURCES` 数组将属性路径与来源 ID 关联。

## 6. 数据导入规范

未来支持 CSV / JSON 批量导入时：
- 必须保留原始值与规范化值
- 每条记录须带来源 ID
- 缺失字段须标记为 missing，不得静默默认值
- 导入失败须返回明确错误信息
- 导入成功但与现有数据冲突时，标记为 reviewed 状态待人工裁决

## 7. 模型审核与数据审核分离

```
数据审核：    draft → reviewed → verified
模型审核：    procedural_schematic → blender_ideal → verified_reconstruction
```

不可因模型精美自动判 verified；模型必须各有独立审核路径。

## 8. 当前数据声明

- 当前 9 种代表矿物数据状态：`verified`（已经对照 Nesse 2013 + RRUFF + Mindat）
- 晶体学参数的"近似值"标识：表示该参数随成分或条件变化
- 当前所有 3D 模型状态：`schematic`（程序化示意，非精确晶面重建）
- 当前显微照片资产状态：缺失（接口与字段已预留）

## 9. 矿物名录版本

- 当前参考名录：IMA-RRUFF 2024-01
- 后续升级时需更新版本字段并保留比对历史
- 不得使用未明确版本的名录宣称"完整覆盖"
